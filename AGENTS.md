# Keyboard-first interaction

Keep keyboard navigation and Vim-style workflows in mind whenever changing the app UI or interactions.

- Every core action should be reachable from the keyboard as well as by pointer, with visible shortcut hints where useful.
- Keep global Vim-style navigation consistent (`j` / `k`, `g` view selection, Escape to cancel) and preserve clear Normal/Insert modes in editors.
- Do not let global shortcuts steal keystrokes while a user is typing in a field or editing a task.
- Keep command palettes and selection modes focused, searchable where appropriate, navigable with arrow keys, and operable with Enter and Escape.
- Update the in-app shortcut help and README whenever shortcuts or navigation behavior change.
